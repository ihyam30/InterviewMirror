# 报告证据契约

## 来源类型

| 类型 | 来源 | 用途 |
|---|---|---|
| `RESUME` | 面试创建时冻结的已确认简历结构化字段 | 经历、项目与技能背景 |
| `JD` | 面试创建时冻结的岗位描述 | 岗位要求和差异分析 |
| `TURN` | 本场回答内容 | 实际能力评分、逐题反馈与改进建议 |

证据目录中的每项有 `evidenceId`、来源类型、来源 ID、位置、精确摘录和 SHA-256。模型响应仅提交 `evidenceIds`；最终报告中的摘录和摘要哈希由服务端从目录回填，避免模型编造来源文本、位置或摘要。

## 评分维度

当前报告 Schema `1.4.0` 固定六维及其含义：

1. `TECHNICAL_DEPTH`：对概念、机制和实现细节的理解。
2. `PROJECT_EXPERIENCE`：项目背景、本人贡献、决策和结果。
3. `JOB_MATCH`：回答与本岗位技术要求的对应情况；无 JD 时不适用。
4. `COMMUNICATION`：表达清晰度、倾听和澄清。
5. `LOGICAL_STRUCTURE`：回答的结构、因果和推理链。
6. `PROBLEM_SOLVING`：诊断、权衡、验证与恢复能力。
每维状态为 `ASSESSED`、`UNASSESSED` 或 `NOT_APPLICABLE`。仅 `ASSESSED` 有 1–5 分和非空回答证据。模型建议分只作为候选值，未被回答证据支持的评分会被服务端清空。总体分数由已评估维度平均值按 20 倍计算；不足 4 个已评估维度时总分留空；提前结束或存在未评估维度时状态为 `PARTIAL`。

`UNASSESSED` 只表示本场回答中没有该维度的直接证据，或模型没有返回有效状态、分数或回答引用；回答较弱但确实涉及该维度时应按行为锚点评为低分，而不是未评估。模型生成提示会要求每项维度独立选择相关 `TURN` 引用。服务端不因有回答或有任意引用就自动提升评分，避免无关回答被误作能力证据。历史报告若有适用维度未评估，可在报告详情或历史列表触发重新评估；重新生成仍会经过相同引用校验，确实没有相关回答时继续显示未评估。服务端日志记录未评估原因代码、维度、是否有回答引用和是否有分数，不记录回答正文。

如果首次报告生成后仍有适用维度未得到有效 `TURN` 引用，系统会再发起一次只针对这些维度的定向复核。复核必须给出有效分数、非空理由及可解析的直接回答引用，服务端才会采用；模型没有找到相关回答时维持 `UNASSESSED`。该复核仅在报告存在未完成维度时发生，会额外增加一次模型调用。

早期 Schema 中的 `CULTURE_MATCH`（协作方式匹配）已从当前报告契约和展示中移除。题库专项报告只展示技术深度、沟通表达、逻辑结构和问题解决四项；项目经验与岗位匹配不适用于专项模式。

## 证据限制

- 所有 turn 必须有且仅有一条对应反馈；缺失反馈会导致报告任务失败并可重试。
- turn 反馈必须引用对应 turn，不可用简历/JD 或另一道题替代。
- 当前仅保留总体评价，模型通过 `overallReviewEvidenceIds` 提交引用。报告生成后，verifier 会结合每条完整回答和可引用的分段证据检查总结，并可重新挑选引用；服务端只接受存在且来源为 `TURN` 的 verifier 引用。核验不支持、调用失败或引用不合法时，总体评价显示中性“未核验”提示，不再把原始回答片段当作评价，状态为 `UNVERIFIED`。历史 `EXTRACTIVE_FALLBACK` 报告在详情和 PDF 中也会清洗，并可重新生成。通过 verifier 的状态记为 `MODEL_SUPPORTED`；没有作答的空报告记为 `NOT_APPLICABLE`。当前报告不再包含“一句话结论”。优势、风险、建议和学习路径也必须有实际回答证据。
- 岗位要求必须引用 JD。缺少回答证据的要求可存在于需求清单，但关联差距标记为 `NOT_EVALUATED`，不归因为知识、经验或表达不足。
- `NOT_EVALUATED` 的理由由服务端统一改为中性说明，模型给出的负面理由和行动建议不会透传；无简历证据时简历分数与状态都显示为 `NO_EVIDENCE`。
- `sourceSnapshotIds` 指回本场冻结来源；查看报告与证据时仍须通过报告 owner 校验。

服务端验证证据 ID 存在、来源类型符合约束并从可信证据目录回填引用。总结 verifier 使用与报告生成相同的配置模型，但通过独立的核验提示重新评估语义支持；这不是独立模型或形式证明，仍可能误判。结构化状态 `MODEL_SUPPORTED` 表示模型核验器接受了该总结和引用，不是人工认证。证据覆盖指标衡量结论是否带合法来源引用，不等于最终语义正确率；应通过人工盲评继续监测。
