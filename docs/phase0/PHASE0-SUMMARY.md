## 基线差异

仓库 `DEVELOPMENT_PLAN.md` 将其称为统一“阶段 0”，未使用 M0a/M0b 命名；原 gate 是简历 F1 ≥90%、题库召回 ≥90%、双模型同集比较、结构化输出 ≥95%、LangGraph checkpoint 保存/恢复以及 50 场费用 ≤¥300。计划另外要求追问相关性均分 ≥4/5 和报告 p95 ≤60 秒。

本次任务增加关键内容召回 ≥95%、模型人工质量均分 ≥4/5，以及 scanned PDF corpus 覆盖；前三项 MinerU 数据实际均达到阈值。计划原报告为五维评分，本阶段用户要求七维，已在契约增加沟通表达、逻辑结构与 JD 限定的工作方式要求证据，并提供旧字段映射。

## 决策

1. 已完成 60 秒低思考力度 GLM 复测，命令与数据见 `SPRING-AI-POC.md`；实测报告 p95 11.716 秒、M06 报告 7.896 秒、结构化/语义 20/20。结果显示保留报告结构并降低 reasoning effort 已满足性能门槛，无需先精简可见内容。
2. 低思考版报告盲评已完成：GLM 得分 4.80/5，达到报告质量门槛；Qwen 得分 3.5333/5。追问评测现已完成：匿名候选 A/B 的质量均分分别为 4.0125/5、4.875/5，均达到 ≥4/5；相关性均分分别为 4.7308/5（78 条）和 4.9808/5（52 条），评分差异≤1的一致率为 92.5%。汇总位于 `data/poc/results/followup-review-v1/scores-blind.v1.json`，两份评审表为 `reviewer-1.completed.csv`、`reviewer-2.completed.csv`。模型映射仍保持盲态。按本阶段量化门槛，可进入 M0b/M1。
3. Q05 的布局漏题必须由回归用例跟踪；不允许仅凭总体平均值忽略该失败案例。
4. 法律/服务形态、真实资料告知授权、删除落实和供应商数据地区仍未确认；本地演示不等于公开服务适用性判断。清单以 2026-10-01 为核对基准，公开上线须复核届时备案、登记、许可要求。
