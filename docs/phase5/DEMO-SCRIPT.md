# 阶段 5 演示脚本

演示使用本地 `demo1` 账号和明确标注的合成简历/题库。面试题、追问和报告由当前模型现场生成；历史报告只用于查看已完成的独立场次，不把预置报告说成刚刚生成。

## 演示前

1. 按 [`LOCAL-DEMO.md`](LOCAL-DEMO.md) 执行 preflight、启动、seed 和 check。
2. 确认 `http://127.0.0.1:15173` 可登录，Backend、PostgreSQL、MinIO 与 Frontend healthy。
3. 真实解析演示才需要 MinerU Worker；只使用预置已确认资料时不需要它。
4. 开始前确认本地模型已配置。模型不可用时，展示简历/题库和面试设置页面即可，停止现场生成，不把失败说成成功。

## 约 5 分钟主路线

| 时间 | 操作 | 讲解重点 |
|---|---|---|
| 00:00–00:30 | 登录后停留在工作台 | 数据按本地账号隔离；本演示资料是合成的。 |
| 00:30–01:00 | 展示已确认简历和题库 | 简历用于综合面试，题库用于专项面试；只有确认资料可选。 |
| 01:00–01:30 | 进入专项面试设置并开始 | 后端再次校验题库归属和确认状态。 |
| 01:30–03:00 | 回答一道题并展示模型追问；必要时展示换题 | 展示回答持久化、动态追问和正在生成状态。模型可能多次追问；等待当次调用结束后可提前结束。 |
| 03:00–03:30 | 结束面试，回到历史报告 | 每场都有独立记录；报告生成中展示进度且不可提前打开。 |
| 03:30–04:30 | 打开报告并浏览总体评价、专项维度和逐题回顾 | 评分只覆盖本场有证据的回答；未作答题不会伪装成已评估。 |
| 04:30–05:00 | 导出 PDF，再返回工作台 | PDF 为登录用户私有文件；展示中文、多页和雷达图版式。 |

要展示综合模式，从第 3 步切换为“综合面试”，选择演示简历并继续相同流程。阶段验收实际完成了 2 场综合和 1 场专项面试，均在 10 分钟内完成。

## 故障时的诚实降级

- **模型服务不可用：** 不开始或不重试现场模型调用；可以展示已确认资料和设置流程。Phase 5 seed 不伪造已完成报告。
- **报告失败：** 历史列表显示失败状态；先检查 Backend 日志和模型配置，再使用页面提供的重试。未显示“报告已生成”前不打开报告。
- **MinerU 不可用：** 只展示 seed 资料，不上传新文件；预置资料绕过解析链路不代表 MinerU 解析成功。
- **PDF 导出失败：** 保留报告页面，确认该报告已 READY、Backend healthy 后重试；不要声称 PDF 已导出。

## 实测计时

数据库记录了 3 次真实浏览器面试（2 次综合、1 次专项），从创建到结束的耗时为 2.98、2.60、1.27 分钟；平均 2.28 分钟，最大 2.98 分钟。计时包含真实 Qwen 生成，但不代表长篇讲解或每次模型响应的固定时长。机器结果见 `data/phase5/results/demo-runs.json`。
