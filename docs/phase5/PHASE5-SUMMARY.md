- 真实供应商 SSE 探针：20/20 成功，TTFT p50 340 ms、p95 531 ms、最大 916 ms；完整响应 p95 约 1.04 秒。
- 该探针测试的是供应商 SSE 接口，不等同于本项目完整结构化面试 API 的首 token；产品接口当前等待结构化结果后返回。
- 3 场完整面试与报告共观察到 17 次 usage 调用：21,971 输入 tokens、7,286 输出 tokens，无 usage 缺失、无模型或报告失败日志。
- 按观测值估算每场 ¥0.010716；假设每月 100 场、Qwen Plus 中国北京非思考模式不超过 128K 的标价，估算 ¥1.07/月，低于 ¥300/月预算。
- 这只是观测样本与公开牌价下的估算，不是账户账单保证；实际区域、思考模式、上下文长度、缓存、优惠和结构修复重试可能改变费用。账户账单未核对。
