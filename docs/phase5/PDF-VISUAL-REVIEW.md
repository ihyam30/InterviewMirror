# 阶段 5 PDF 视觉验收

至少下载并检查三个不同综合 / 专项报告的真实 PDF，使用 Poppler 渲染全部页面到临时 PNG，逐页目视检查；检查所有页面文字边界、分页与图表，并目视查看各 PDF 的首页、分页交界页和末页。

检查项目：

- 中文字形无方框、丢字、重叠、截断或乱码；标题、总体评价、能力维度、逐题问题和回答、建议均可读。
- 问题和回答之间有空行；逐题之间留白；列表各项有间距。
- PDF 不含岗位差异分析、证据引用或“下一步”部分。
- 单页与多页内容均没有越过页边界；分页标题清楚，页脚/页码如存在则一致。
- 使用 `pdfinfo` 检查页数和页面尺寸；用 `pdftotext -layout` 辅助查找空白页面/段落顺序，但文本抽取不能代替目视审核。
- 验证 PDF 来自登录用户自己的报告；跨用户访问仍由 report owner 查询约束。
