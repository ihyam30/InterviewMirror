# OCR fixture

`scanned-resume.pdf` is generated by this project: a single page drawing the text
`张三 / Skills: Java Redis PostgreSQL / Project: API development / Experience: backend engineer`
as a bitmap image, with no text layer and no drawn text operators.

It is used by `ResumeParseIsolationTest` to prove that a real OCR run, and a force-killed
OCR run, both keep their scratch files inside the parse job directory instead of the
system temporary directory. Regenerate with Pillow and reportlab if it is ever lost.
